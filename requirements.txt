# The MCP SDK ships the server class both faces mount (`MCPServer`, formerly
# `FastMCP`); the separate `fastmcp` distribution is deliberately NOT a
# dependency.
#
# The major is pinned, and that is the point. An unbounded `mcp>=1.0.0` was
# how 2.0 arrived unannounced: it renamed `mcp.server.fastmcp` to
# `mcp.server.mcpserver`, so every *fresh* install died at startup with
# ModuleNotFoundError while every venv resolved months earlier kept working.
# The bug was invisible to anyone who already had one. Raising this ceiling
# means porting the faces, not editing a number.
mcp>=2.0,<3

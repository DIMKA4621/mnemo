## Devserver gotchas worth remembering for the next screenshot/demo session

- `_fixture_provider_key()`'s local key literally includes the HF org prefix (`intfloat/multilingual-e5-large`) — don't assume it matches the CLI's trimmed display string.
- The auto-update simulation is **on by default and fires within ~20s of boot** — always neutralize `_SETTINGS["auto_update"]` and `_UPDATE_STATE["current_tag"]/["update_available"]` first, before doing anything else, or race the countdown.
- `.pane` elements: only the first two (banks, files) get an inline `style.width` from user resize; the third (content) is `flex: 0 1 auto` and must have its width set explicitly (plus `flexGrow`/`flexShrink` pinned to `'0'`) to actually widen — narrowing its siblings alone does nothing but leave a blank gap.
- `SERVICE_VERSION = "3.0.0-mock"` shows up verbatim in the sidebar footer ("v 3.0.0-mock") — worth overriding to the real current tag for anything screenshot-facing, since "-mock" reads as a broken/dev build to anyone who doesn't know this is a fixture server.

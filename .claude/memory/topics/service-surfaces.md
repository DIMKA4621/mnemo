# Поверхні служби: обличчя, токени, імена тулів

Що назовні віддає служба, чим воно розділене й чому саме так. Проводка
проєкту (що пише `init`) — `topics/project-wiring.md`; встановлення й
життєвий цикл — `topics/install-lifecycle.md`.

## Чотири поверхні, розділені токеном

- `/api/*` — приватний канал кабінету, **прихований з OpenAPI**.
- **`/mcp?token=<токен банку>`** — MCP для агентів, **без сегмента шляху**:
  токен визначає банк і більше ніщо.
- `/mcp-admin` — керування банками, **тільки сервісний токен**.
- `/mcp-tools/<tool_name>` — дзеркало тулів звичайним HTTP для людини, видне
  у Swagger (`/docs`), віддає **байт-у-байт** той самий текст.

Жоден із двох токенів не відкриває обличчя іншого.

**Чому в `/mcp` немає сегмента банку.** Сегмент, заголовок `X-Mnemo-Bank` і
правило «якщо банк один» — це три другі джерела істини про те, який банк
мається на увазі, і кожне вільне розійтися з поданим токеном.

## Імена тулів — без префікса

Тули звуться `search`, `tree`, `reindex` — **без** `memory_`: клієнт і так
подає їх як `mcp__<server>__<tool>`.

## Токени

- **Кожен банк має свій токен** (`banks.json`, 48 hex). Це least privilege, а
  не стіна: сервісний токен відкриває все.
- **`bank_id` виводиться (sha1 кореня), токен видається.** Наслідок, який уже
  коштував вади: та сама тека завжди повертається з тим самим id, тож per-id
  стан у процесі (`_cancelled` у черзі) отруює наступний банк —
  `api_remove_bank` мусить знімати скасування **й на гілці успіху**.

## Багатоклієнтність — наслідок форми, не фіча

`stateless_http=True`, тож N консолей у тому самому проєкті = N зʼєднань до
вже піднятої служби, **без локу й без власника**; банки — реєстр, тож сьомий
проєкт коштує запис, а не другий резидент.

**Віддалена служба в README свідомо не описана** (рішення користувача):
архітектурно можлива — хост є змінною скрізь, — але живцем не піднімалась, і
має дві межі, які роблять із неї не «просто інший хост»: `.md` мусять лежати
**там, де служба** (watcher індексує свою ФС), і TLS немає — поза loopback це
довірена мережа чи тунель. Писати, коли перевіримо.

## MCP SDK 2.0 — як саме монтується обличчя

MCP-клас у SDK 2.0 зветься **`MCPServer`** (`mcp.server.mcpserver`), у 1.x був
`FastMCP`. `stateless_http` / `streamable_http_path` переїхали в
`streamable_http_app(...)`, а `session_manager` **кидає**, поки той не
викликано — тримається на тому, що `api` монтує обличчя **на імпорті**.
